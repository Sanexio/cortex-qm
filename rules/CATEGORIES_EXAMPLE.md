# Themen-Kategorien — Beispiel-Inhalte

> **Demo-Hinweise**, nicht echte Praxis-Daten. Tenants füllen ihre
> konkreten Inhalte in `02_Vorlagen_und_Anlagen/01..12/` ein und in
> `01_Dokumente/` heraus. Konkrete Lieferanten-, Geräte-, Räumlich-
> keiten- und Personen-Bezüge gehören in die `*_TENANT.md`-Files.

## Struktur eines Themen-Eintrags

```
### <Themen-Nummer> <Themen-Name>

**Pflicht-Inhalte:**     <was muss eine Praxis hier mindestens haben>
**Optionale Inhalte:**   <was hängt von Praxis-Profil ab>
**Regulatorische Anker:** <Gesetze/Richtlinien, die hier greifen>
**Beispiel-Dokumente:**  <typische Datei-Namen, anonymisiert>
```

---

## 01 Hygiene_Desinfektion

**Pflicht-Inhalte:**
- Hygieneplan (Standort-spezifisch)
- Reinigungs- und Desinfektionsplan (R&D-Plan)
- Hautschutz- und Handschuhplan

**Optionale Inhalte:**
- Lieferanten-Hygieneleitfäden (PDF von Hersteller)
- Standort-Anlagen (z.B. mehrere Behandlungsräume mit unterschiedlichen Hygiene-Stufen)

**Regulatorische Anker:** IfSG §36, KRINKO/BfArM, TRBA 250, RKI-Empfehlungen

**Beispiel-Dokumente:**
```
Hygieneplan.docx
R+D-Plan_<Standort>.docx
Hautschutz-und-Handschuhplan.docx
PSEUDO-Hersteller_Hygieneleitfaden.pdf
```

## 02 Infektionsschutz_Meldewesen

**Pflicht-Inhalte:**
- Verfahrensanweisung MRE (multiresistente Erreger)
- IfSG-Meldepflichten-Liste mit Meldeweg-Definition
- Verfahrensanweisung respiratorische Infekte (Influenza/COVID/RSV)

**Optionale Inhalte:**
- Verfahrensanweisung virale Diarrhoe (Norovirus/Rota)
- Verfahrensanweisung Telefon-Triage bei Verdachts-Infekt

**Regulatorische Anker:** IfSG §6 + §7 (namentliche Meldepflicht),
KRINKO-MRE-Empfehlung

**Beispiel-Dokumente:**
```
Verfahrensanweisung_MRE.docx
IfSG_Meldepflichten.docx
Verfahrensanweisung_Telefon_Infekt.docx
```

## 03 Notfallmanagement

**Pflicht-Inhalte:**
- Notfallplan (BLS/ALS-Ablauf, Defibrillator-Bedienung)
- Notfall-Triagekriterien
- Notfallausstattungs-Bestandsliste mit Verfallsdatums-Check

**Optionale Inhalte:**
- Reanimations-Übungsprotokoll
- Notarzt-Kontaktliste (länderspezifisch)

**Regulatorische Anker:** ärztliche Berufsordnung,
Reanimations-Leitlinien (ERC/GRC)

**Beispiel-Dokumente:**
```
Notfallplan.docx
Notfallkriterien.docx
Notfallausstattung_Bestandsliste.docx
```

## 04 Patientenversorgung_Diagnostik

**Pflicht-Inhalte:**
- SOPs für die häufigsten klinischen Vorgänge der Praxis
  (Anamnese, Blutentnahme, Wundversorgung, Impfung, EKG, …)
- Anleitungen zur Geräte-Bedienung mit Patient-Bezug

**Optionale Inhalte:**
- Praxisspezifische klinische Pfade (Asthma, Diabetes, …)
- POCT-Protokolle (Point-of-Care-Testing — patientennahe
  Labordiagnostik wie HbA1c, INR)

**Regulatorische Anker:** ärztliche Berufsordnung, Impfempfehlungen
STIKO, RILI-BÄK (Rili-BÄK für POCT)

**Beispiel-Dokumente:**
```
SOP_Anamnese.docx
SOP_Blutentnahme.docx
SOP_Impfung.docx
SOP_Wundversorgung.docx
QC_Protokoll_POCT.docx
```

**Beispiel-Dokumente:**

```
Schweigepflichtsbelehrung.docx
Aufbewahrungsfristen.docx
```

**Pflicht-Inhalte:**

**Regulatorische Anker:** G-BA QM-Richtlinie, QEP-Manual

**Beispiel-Dokumente:**

## 08 Personal_Organisation

**Pflicht-Inhalte:**
- Organigramm (Strukturskizze, anonymisiert; konkrete Namen
  ins Tenant-File)
- Aufgaben/Verantwortlichkeiten-Matrix (RACI-Stil)
- Delegations-Regelung (welche ärztliche Aufgabe darf die MFA
  selbständig ausführen)

**Optionale Inhalte:**
- Kürzelliste (Initialen + voller Name — Tenant-File)
- Aushilfen-Liste

**Regulatorische Anker:** BÄO §29 (Delegation), Vereinbarung
über Delegation Berufsverbände

**Beispiel-Dokumente (im OSS-Repo: Skelett):**
```
Organigramm_Skelett.docx
Aufgabenmatrix_Skelett.docx
Delegations-Regelung.docx
```

## 11 OP_Eingriffe_SSI

**Pflicht-Inhalte (sofern OP-Tätigkeit in der Praxis):**
- SSI-Risikoeinstufung (Surgical Site Infection)
- SOP für jeden Eingriffstyp
- Sterilisations-Verfahren-Dokumentation
- Eingriffs-Protokoll-Vorlage

**Optionale Inhalte:**
- Patienteneinwilligungs-Mustertexte (nicht patientenbezogen)
- Komplikations-Statistik (aggregiert, DSGVO-konform — siehe
  CORE_RULES.md DSGVO-Hardstop)

**Regulatorische Anker:** KRINKO-Empfehlung „Prävention
postoperativer Wundinfektionen", MPDG

**Beispiel-Dokumente:**
```
SSI_Risikoeinstufung.docx
SOP_<Eingriffstyp>.docx
Sterilisationsprotokoll.docx
```

## 12 Abfallentsorgung

**Pflicht-Inhalte:**
- Abfallentsorgungs-Verfahrensanweisung mit AS-Schlüssel-Zuordnung
  (Abfallschlüssel-Nummer nach AVV / EAV)
- Sammelbehälter-Konvention (Farbe, Beschriftung, Standort)
- Entsorgungs-Dienstleister-Kontakt + Übergabeprotokoll

**Optionale Inhalte:**
- Schulungs-Unterlage „Abfalltrennung in der Praxis"

**Regulatorische Anker:** KrWG (Kreislaufwirtschaftsgesetz), AVV
(Abfallverzeichnis-Verordnung), TRBA 250 für infektiöse Abfälle
(AS 18 01 03*)

**Beispiel-Dokumente:**
```
Anlage_Abfallentsorgung.docx
Sammelbehaelter_Konvention.docx
```

## Anti-Pattern: Was NICHT in dieses OSS-Repo gehört

❌ Konkrete Lieferanten-Hygieneleitfäden mit Hersteller-Name (die
   liefern Hersteller ohnehin selbst, gehören als PDF ins Tenant-Repo
   oder bleiben außerhalb der Versionskontrolle).
❌ Personennamen jeglicher Art.
❌ Standort-Adressen oder Raumpläne mit konkreten Bezeichnungen.
❌ Telefonnummern oder Mail-Adressen einer einzelnen Praxis.
❌ Konkrete Medizinprodukt-Serien-/Inventarnummern.
❌ Konkrete Patientenfälle.

All das gehört in die **Tenant-Files** oder ins jeweilige
Tenant-Repo. Pseudo-Beispiele („PSEUDO-Hersteller", `<Standort>`,
`<Eingriffstyp>`) werden hier im OSS-Repo NICHT durch echte Daten
ersetzt.
